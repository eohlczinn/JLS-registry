# Conta e login

Use e-mail e senha para criar ou acessar a conta. A senha deve ter pelo menos 6 caracteres. O Google Login exige que `GOOGLE_CLIENT_ID` esteja configurado no backend e que a origem do site esteja autorizada no Google Cloud.

No dashboard é possível visualizar bibliotecas, downloads e histórico. Em perfil, o usuário pode alterar nome, bio, foto, GitHub e site quando essas opções estiverem habilitadas.
